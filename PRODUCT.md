# Ezpath

Ezpath is an accessibility-first transit planner. Travellers choose mobility requirements, walking limits, and budget, compare journeys, inspect accessibility evidence, and save itineraries offline. Operators inspect network facilities and simulate disruptions. The default environment uses demonstration data; the landing page labels its illustrative route accordingly.

The existing React, TypeScript, Vite, Zustand, MapLibre and Tailwind application remains the implementation. The redesign requested by the user replaces AccessPath branding with Ezpath and adds a premium visual identity, GSAP and Framer Motion. Existing persistence keys and service identifiers remain unchanged to preserve stored journeys and integrations.
